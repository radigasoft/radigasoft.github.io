Performa dan multi-core (WAJIB): semua pekerjaan render yang berat
(rasterisasi permukaan, tekstur per piksel, bayangan, downsample,
pelapukan) harus berjalan paralel di SEMUA core CPU dan bebannya dibagi rata:
- jumlah thread = jumlah prosesor logis (GetSystemInfo, dwNumberOfProcessors,
  minimal 1, maksimal 64)
- bagi pekerjaan jadi unit kecil (satu baris, atau pita 8-16 baris, atau
  tile kecil). Tiap thread mengambil unit berikutnya lewat penghitung
  bersama dengan InterlockedIncrement sampai habis. DILARANG membagi jumlah
  baris secara tetap per thread, karena thread yang kebagian area berat jadi
  penentu waktu dan core lain menganggur.
- pola thread: TThread.Create(True), FreeOnTerminate := False, Resume,
  WaitForMultipleObjects pada semua handle, lalu Free tiap thread.
- tiap thread hanya menulis ke baris/area miliknya. Tidak ada variabel global
  yang diubah bersama. Konteks per-thread dikirim lewat field thread atau
  record parameter.
- Random dari System TIDAK aman untuk thread (RandSeed global). Di kode yang
  berjalan di thread, semua keputusan acak dihitung dari hash (Hash2 dan
  turunannya) berdasarkan Seed dan koordinat. Random hanya boleh dipakai di
  thread utama.
- yang dipararelkan adalah pekerjaan di dalam SATU rumah (bukan satu thread
  per rumah), supaya satu rumah pun memakai semua core.
- bagian yang urut atau saling bergantung (penyusunan objek, y-sort) tetap di
  thread utama, sisanya paralel.

function Hash2(ix, iy, seed: Integer): Single;
var
  h: Int64;
begin
  h := ((Int64(ix) and $FFFFFFFF) * 374761393) and $FFFFFFFF;
  h := (h + ((Int64(iy) and $FFFFFFFF) * 668265263)) and $FFFFFFFF;
  h := (h + ((Int64(seed) and $FFFFFFFF) * 1597334677)) and $FFFFFFFF;
  h := ((h xor (h shr 13)) * 1274126177) and $FFFFFFFF;
  h := h xor (h shr 16);
  Result := (h and $FFFFFF) / 16777216;
end;

function VNoise(x, y: Single; seed: Integer): Single;
var
  ix, iy: Integer;
  fx, fy, a, b, c, d: Single;
begin
  ix := Floor(x);
  iy := Floor(y);
  fx := x - ix;
  fy := y - iy;
  fx := fx * fx * (3 - 2 * fx);
  fy := fy * fy * (3 - 2 * fy);
  a := Hash2(ix, iy, seed);
  b := Hash2(ix + 1, iy, seed);
  c := Hash2(ix, iy + 1, seed);
  d := Hash2(ix + 1, iy + 1, seed);
  Result := a + (b - a) * fx + (c - a) * fy + (a - b - c + d) * fx * fy;
end;

function Clamp255(v: Single): Integer;
begin
  if v < 0 then
    v := 0
  else if v > 255 then
    v := 255;
  Result := Round(v);
end;

procedure PutDotBlend(bmp: TBitmap32; px, py, rx, ry: Single; r, g, b, a: Single);
var
  xi, yi, x0, x1, y0, y1, o: Integer;
  d, alphaFactor, finalAlpha: Single;
  c: TColor32;
  qr, qg, qb, qa: Integer;
begin
  x0 := Max(0, Floor(px - rx - 1));
  x1 := Min(bmp.Width - 1, Ceil(px + rx + 1));
  y0 := Max(0, Floor(py - ry - 1));
  y1 := Min(bmp.Height - 1, Ceil(py + ry + 1));
  for yi := y0 to y1 do
    for xi := x0 to x1 do
    begin
      d := Sqrt(Sqr((xi + 0.5 - px) / rx) + Sqr((yi + 0.5 - py) / ry));
      if d >= 1.0 then Continue;
      alphaFactor := (1.0 - d * d) * a;
      if alphaFactor <= 0 then Continue;
      o := yi * bmp.Width + xi;
      c := bmp.Bits[o];
      qr := (c shr 16) and $FF;
      qg := (c shr 8) and $FF;
      qb := c and $FF;
      finalAlpha := Min(1.0, alphaFactor);
      bmp.Bits[o] := Color32(
        Clamp255(qr + (r - qr) * finalAlpha),
        Clamp255(qg + (g - qg) * finalAlpha),
        Clamp255(qb + (b - qb) * finalAlpha),
        255
      );
    end;
end;

(Ini hanya contoh gaya. Di RumahDesa3.pas semua identifier tingkat-unit
tetap harus berawalan "Rd".)

============================================================================
10. FORMAT KELUARAN
============================================================================
Serahkan dua file:
1. RumahDesa3_Catatan.txt : resep lengkap, kamus variasi, parameter,
   keputusan desain, status pekerjaan dan hal yang belum selesai.
2. RumahDesa3.pas : kode lengkap dan siap dipakai, tanpa komentar.
Kalau kamu bisa membuat file, buat kedua file itu. Kalau tidak, kirim
masing-masing dalam satu blok kode. Kalau kode terlalu panjang untuk satu
balasan, potong HANYA di batas antar-prosedur, akhiri balasan dengan tepat
"[BERSAMBUNG]", dan lanjutkan saat aku mengetik "lanjut" tanpa mengulang kode
yang sudah dikirim dan tanpa ringkasan.
Setelah kode selesai, tulis penutup maksimal 8 baris: cara pakai dari form
(uses RumahDesa3; lalu BikinRumahDesa3(Image321);) dan kelemahan yang kamu
ketahui. Untuk revisi berikutnya, kirim RumahDesa3.pas penuh dengan nama
yang sama.

Mulai sekarang. Jangan bertanya.
